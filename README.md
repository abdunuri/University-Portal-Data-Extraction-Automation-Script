# University Portal Data Extraction Automation Script

This repository documents a Python automation project for logging into a university portal, extracting grade or report data, and storing the collected information in SQLite.

## Main Concept

The project is a web automation and data extraction script. Its purpose is to reduce manual portal checking by using browser automation to navigate a university system, collect structured academic data, and save the results locally for later review or reporting.

## What It Demonstrates

- Browser automation with Playwright
- Login and portal navigation flows
- Structured data extraction from web pages
- Local persistence with SQLite
- A practical automation workflow for repetitive academic admin tasks

## Intended Use

Use this as a reference or starting point for automating university portal workflows where data needs to be collected consistently and stored outside the browser.

## Notes

Credentials, portal URLs, and selectors should be kept private and configured safely outside source code when adapting this project.
